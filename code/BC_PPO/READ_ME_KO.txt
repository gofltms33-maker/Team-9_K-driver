BC + PPO 과거 실험 모델 공유 자료

모델: v118 round004, 가감속 고정 / 차로변경 보정층 PPO 학습
개발 평가300회: 완주255(85%), 충돌40(13.33%), 경로막힘4, 신호위반1
별도 평가100회: 완주86(86%), 충돌11(11%), 경로막힘2, 신호위반1
두 평가는 같은 가중치를 사용했다. 충돌률5% 미만 목표는 미달성이다.
당시 환경은 prefillOFF이며, 최근400초 대기/1.5배 교통량/새 경로 환경이 아니다.

실행: 압축 해제 후 이 폴더에서 실행한다.
  python run_model.py --seed 1024000
화면 없이 확인:
  python run_model.py --nogui --seed 1024000 --episodes 2
기존 팀 Python 환경과 SUMO(평가 당시1.27.1)를 사용한다.
SUMO_HOME이 설치 폴더를 가리키도록 설정해야 한다.

파일:
- model/: 실제 평가에 사용한 선택 가중치와 실행용 상대 경로 설정
- fixture/: 당시 고정 도로/일반차 수요/차량 특성. 재생성할 필요 없음
- train_local_bc.py: 기본 BC 단계(v107)에 보관된 학습 코드
- train_trust_region_correction.py: 실패 시연 보완 단계에 보관된 코드
- train_warmstart_ppo.py: 해당 PPO 실행 시 보관된 학습 코드
- collect_audited_course_data.py, train_bc_ppo.py: 당시 시연 수집 코드
- ppo_initialization/: PPO 학습 시작점 가중치
- training_logs/, evaluation/: 당시 학습 로그와 평가 기록
- provenance/: 수정하지 않은 원본 설정, 실행 명령, 소스 출처/해시, 데이터 보유 현황

PPO 주요 값:131072스텝, rollout2048, epoch2, actor LR2e-6,
gamma0.999, GAE0.95, clip0.03, targetKL0.002, BC보조손실0.05.
학생 입력은104차원이며 평가 중 교사 운전/별도 행동 필터를 사용하지 않는다.

재학습 범위:
이 묶음은 모델 실행과 학습 코드 검토용이다. 학습용 시연 NPZ는 포함하지 않았다.
그중 초기 시연5개는 로컬에도 없어 당시 전체 학습을 그대로 재현할 수는 없다.
원래 학습 명령은 C드라이브 절대 경로를 포함하는 기록이므로 그대로 실행하지 않는다.
재학습하려면 시연 데이터를 다시 준비하고 명령의 경로를 해당 컴퓨터에 맞춰야 한다.
별도 명시한 보관 소스 이외의 보조 의존 파일은 현재 로컬 사본이다.
원본 프로젝트/결과 파일은 수정하지 않았다.

검증 상태:
가중치 로딩,104차원 입력에 대한 신경망 출력, 원래 환경 해시,
BC/PPO 스크립트 로딩은 확인했다.
현재 도구 환경에서 로컬 SUMO 연결이 지연되어 전체 주행 재현 검사는
완료하지 못했다. 상세 결과는 provenance/package_checks.json에 있다.
